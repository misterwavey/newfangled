How to use this workbench

Turn to browse Home and outputs 1–8. Click Program on Home to edit the tempo. On an output, click Program to browse parameters, turn to choose one, then click to edit its value. Click again to leave value editing. Hold the encoder for 500 ms to return to output browsing; the Back button performs that hold. Output parameter browsing also offers CV SETUP and CV MON. In CV SETUP choose DEST, SRC, DEP and BIAS; negative DEP inverts modulation. CV sliders now drive these routes. Hold Program on Home in VIEW mode to open source, PPQN, Run-input, CV monitor, swap and calibration settings. Choose SRC EXT and match PPQN to the clock below. Start arms playback; in GATE mode the Run gate must also be high. Start toggles transport. Hold Program and press Start on hardware to reset phase. The Phase reset button performs that gesture.

Play controls virtual time independently of the module buttons. Turning advances 4 ms; clicking advances 50 ms so debouncing works while paused.
